# Nexus design system

Use obsidian surfaces, layered indigo diffusion, thin luminous borders and spectral accents. The dashboard uses an editorial serif title, a spaced sans-serif wordmark and monospace system metadata. Keep the network prominent. Other panels should remain readable at a glance. Agent icons use simple line geometry and each node pairs a label with its identity color. Accent colors follow the canonical agent catalog.

The reusable triangle-and-circle mark is defined as SVG geometry. The dashboard network uses a perspective-projected mesh with depth-weighted particles, rotating orbital paths, and animated signals. The centered Core is its sole entry point. Agents and saved connections have their own workspaces. Decorative animation remains subtle and is independent of runtime activity. Offer motion and rendering controls, accessible names, visible focus indicators, a keyboard-command dialog and a responsive layout.
